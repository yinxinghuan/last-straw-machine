# 《Today's Last Straw》视觉方向

## 情绪承诺

先让玩家觉得“今天肯定要出事”，再把结果短剧变成一次有因有果的情绪翻盘。紧张来自筹码反复擦过三个坏结果，不来自堆叠说明或复杂数值。

## 选定方向：事故预测报社机器

- 背景：骨白旧纸与墨黑印刷纹理；机器内部为深墨色。
- 强调色：警报红 `#ef3b2d`、脏黄 `#f4c84b`、冷青 `#8ed8cf`。
- 字体：系统无衬线粗体，窄字距，大写英文；中文界面走同一 i18n，但正式海报只用英文标题。
- 形状：硬边、斜切角、粗 2px 墨线；避免圆润 SaaS 卡片。
- 头像筹码：真实头像圆形裁切，外包双层红黑金属圈；这是唯一圆形主元素。
- 钉与落袋：像新闻编辑部的机械排字槽，三个标签始终大而短：`THE BOSS / REPLY ALL / THE SPILL`。

## 屏幕结构

1. 顶部 18%：小眉题 + 两行标题 + 一句行动指令。
2. 中部 64%：完整 Plinko 机器；头像吊槽、钉、三个结果口都在首屏。
3. 底部 18%：一个全宽投放按钮；游戏开始后按钮变成短状态句，不增加第二操作。
4. 结果态：视频/静帧全屏铺底，顶部危机标签，底部反转结语和单个重试按钮。

## 动效与演出

- 吊槽匀速往返，头像有 2° 的机械摆动。
- 碰钉时钉闪黄 90ms、筹码压缩 70ms、机器轻震 45ms。
- 入袋后红色警报条从两侧合拢；危机标题砸入，再切结果视频。
- 反转末拍只出现一次冷青盖章和三音上行，不使用金币雨、烟花或彩带。

## 响应式

- 普通 DOM 内部适配，不依赖整页 transform。
- 320×568 时隐藏眉题、标题降至 31px、机器上下间距压缩，但三个结果口和 44px 投放按钮保留。
- 视频使用 `object-fit: cover`；人脸与关键手部放在中央 70% 安全区。

## 反模式

- 不做老虎机灯海、概率表、货币、等级或多按钮选择。
- 不把三种结果提前写成长文解释。
- 不以无关荒诞替代情绪反转。
- 不让固定演员具有东亚定向特征，不在生成影像中出现可读文字、假字幕、Logo 或 UI。
- 不把玩家头像贴在角落充当“个性化”；它必须是实际参与碰撞并决定结果的筹码。
